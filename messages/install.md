# SquareTable

SquareTable edits plain-text tables in Sublime Text 4. It is a fork of
Table Editor, extended for multiline Pandoc and reStructuredText grid
tables with rowspans and colspans.

SquareTable is disabled until you enable it. From the command palette run:

- SquareTable: Enable for current view
- SquareTable: Enable for current syntax

Then type a row such as `|Name|Phone|`, press Ctrl+K then Enter, and use
Tab and Shift+Tab to move between cells.

The README lists every key binding, table syntax and setting:

- Sublime Text: Preferences > Package Settings > SquareTable > README
- Online: https://github.com/cjdbarlow/squaretable-st
